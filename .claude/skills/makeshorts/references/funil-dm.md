# Funil "comente PALAVRA" → DM automática

View sem destino não vira nada. O funil transforma quem comentou em lead, e ainda turbina o post:
cada comentário é sinal de engajamento que empurra o alcance.

```
short com CTA "Comenta IA"  →  pessoa comenta "IA"  →  resposta pública no comentário
                                                    →  DM com botão  →  clique  →  link (curso/lista/call)
                                                    →  follow-up se não clicou
```

## Configuração (ManyChat, Instagram/Facebook) — feita uma vez, à mão
1. Conta Instagram **profissional** ligada a uma página do Facebook; conectar no ManyChat.
2. **Automation → New automation → "Auto DM from comments"**.
3. Gatilho: **qualquer post ou reel**, palavra-chave fixa (ex.: `IA`). Use **sempre a mesma palavra**
   para não precisar mexer a cada post.
4. Resposta pública ao comentário (variar): "Te mandei no direct!", "Confere a DM 👀".
5. DM 1 com **botão** ("Quero o link") — o link só vai depois do clique (a plataforma exige opt-in).
6. DM 2 com o link (curso gratuito INEMA.CLUB, lista, material).
7. Follow-up depois de algumas horas para quem não clicou.

## Variações
- Em vez de link, abrir conversa: "Qual é tua maior dificuldade com X?" → leva a atendimento.
- Palavra por nicho: `SEO`, `ROTEIRO`, `CLAUDE`… uma por campanha.

## Notas
- É um serviço pago de terceiros; conferir plano e preço atuais antes de assinar.
- Acompanhe a taxa de clique no botão; se cair, troque o texto da DM, não a palavra.
- Sem ManyChat: o CTA pode apontar para "link na bio" — converte menos, mas funciona.
