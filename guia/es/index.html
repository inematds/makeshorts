Qué es

Una fábrica de shorts dentro de Claude Code

MakeShorts es una skill (/makeshorts) con scripts de apoyo. Tú entregas un tema, un enlace o un clip grabado; ella te devuelve el short editado, revisado y listo para programar.

🧩 Orquesta, no reinventa

Llama a lo que ya funciona: HyperFrames para editar, inemavox para voz y transcripción, HeyGen para avatar, Metricool para programar.

📐 Fórmula fija, tema variable

Todo short sigue gancho → gancho secundario → 3 pasos → CTA. Tres versiones de guion para que elijas.

✅ Calidad medida

Nada sale sin pasar por qa_short.py: duración, formato 1080x1920, loudness, gancho visual, hashtags y CTA.

Cómo funciona

Siete etapas, un solo pedido

Cada etapa puede hacerse por separado (los 5 modos) o en secuencia. Las que cuestan dinero o publican siempre piden tu confirmación.

Guion→ Voz o avatar→ B-roll real→ Edición 9:16→ QA→ Programar→ Embudo de DM
1

Guion

~75 palabras, gancho en 3 s, datos solo de fuente oficial, 3 versiones.

2

Voz / rostro

Grabación humana, voz sintética (local o API) o avatar HeyGen.

3

Edición

Visual arriba, rostro abajo, subtítulo palabra por palabra, punch-in y SFX.

4

Publicación

Descripción con beneficio, hasta 5 hashtags, etiqueta de IA, Metricool.

Requisitos previos

Lo que debe estar en la máquina

Lo básico corre en cualquier Linux o Mac. La GPU e inemavox son opcionales: sin ellos, cambia los backends por API (ver VPS).

Claude Code

Con la suscripción. Es donde corre la skill.

npm i -g @anthropic-ai/claude-code

ffmpeg + Python + Node

Edición, QA y el motor HyperFrames.

sudo apt install -y ffmpeg python3 nodejs

HyperFrames

Motor de edición HTML → MP4, corre en CPU.

npx hyperframes skills update general-video
Guía de uso · paso a paso

Del clone al primer short

Cinco pasos. Los comandos son los del repositorio, listos para copiar.

1

Clona e instala

El instalador revisa las dependencias, enlaza la skill en ~/.claude/skills/makeshorts (symlink) y crea el .env.

git clone https://github.com/inematds/makeshorts.git && cd makeshorts
bash scripts/instalar.sh --check   # solo revisa
bash scripts/instalar.sh           # instala la skill + crea .env
2

Elige los backends en el .env

Una línea por etapa. En la máquina con GPU todo queda local; en otro lugar, cámbialo por API.

MS_VOZ=inemavox          # inemavox | edge | openai | elevenlabs
MS_TRANSCRICAO=inemavox  # inemavox | groq | openai
MS_IMAGEM=flux-local     # flux-local | nenhuma
MS_AVATAR=nenhum         # heygen | nenhum
MS_PUBLICAR=metricool   # metricool | manual
3

Pide el short

En Claude Code, llama a la skill o habla con naturalidad. Ella deduce el modo a partir del pedido.

/makeshorts 3 guiones sobre Claude Code en el celular        # modo guion
/makeshorts edita ~/Downloads/clip.mp4                        # modo humano
/makeshorts short sobre https://site-da-ferramenta, sin grabar # modo IA
/makeshorts 5 shorts de IA gratis de la semana, uno por día a las 18h # modo lote
4

Pasa por el control de QA

La skill lo ejecuta sola, pero también puedes correrlo a mano. Exit 1 reprueba y dice qué corregir.

python3 .claude/skills/makeshorts/scripts/qa_short.py final.mp4 --caption legenda.txt
✅ duração        31.2s
✅ formato        1080x1920
✅ loudness       -14.1 LUFS
✅ gancho visual  sem tela preta no início
✅ hashtags       4: #claudecode #ia #automacao #shorts
RESULTADO: APROVADO
5

Programa y activa el embudo

La skill arma la descripción y los hashtags, te muestra todo y solo programa en Metricool después de tu "adelante". El CTA "Comenta IA" se convierte en un DM automático con el enlace (ManyChat, configurado una sola vez).

/makeshorts publica final.mp4 en Instagram, TikTok y Shorts en el mejor horario
Correr en un VPS

Sin GPU, sin voz local: solo cambia el .env

No cambia ni una línea de código. Los scripts voz.py y transcreve.py leen el backend del .env y llaman a la API correcta.

🖥️ Máquina con GPU

Voz: inemavox (chatterbox, voz clonada local) · Transcripción: inemavox (Whisper large-v3) · Imagen: flux-local.

☁️ VPS

Voz: edge (gratis), openai o elevenlabs (tu voz clonada) · Transcripción: groq u openai · Imagen: nenhuma (b-roll real).

# .env típico de VPS
MS_VOZ=edge
EDGE_VOZ=pt-BR-AntonioNeural
MS_TRANSCRICAO=groq
GROQ_API_KEY=gsk_...
MS_IMAGEM=nenhuma

# probar cada pieza
python3 scripts/voz.py --texto "Prueba de voz." --out /tmp/t.mp3
python3 scripts/transcreve.py --in /tmp/t.mp3 --outdir /tmp/tr

Instalación completa en Ubuntu, costos de referencia y uso con tmux: docs/vps.md (en portugués).
